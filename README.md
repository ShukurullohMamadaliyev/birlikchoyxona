# Ibrohim Ota Choyxonasi - QR Kodli Mobil Menyu

Ushbu loyiha **"Ibrohim Ota choyxonasi"** uchun maxsus ishlab chiqilgan zamonaviy, tezkor va 100% mobil moslashuvchan QR-menyu veb-ilovasi.

## 🌟 Imkoniyatlari
- **Zamonaviy Choyxona Dizayni**: To'q qizil (Burgundy) va oltin ranglar uyg'unligi, sifatli taom rasmlari.
- **Katta yoshdagilar uchun qulaylik**: Katta yozuvlar, yorqin rasmlar va oson bosiluvchi (katta) tugmalar.
- **Tezkor qidiruv va toifalar**: Milliy taomlar, Shashliklar, Fastfud, Salatlar & Non, Ichimliklar.
- **Interaktiv savatcha (Floating Cart)**: Pastda yopishib turuvchi savatcha paneli.
- **Xona / Stol raqami (Majburiy)**: Buyurtma berishdan oldin xona raqamini kiritish yoki tezkor tanlash imkoniyati (QR kod orqali `?xona=5` kabi avtomatik aniqlash ham mavjud).
- **Kreativ Tasdiqlash Modali**: *"Taomlarimiz ma'qulmi? 😊"* - buyurtmani tasdiqlash yoki yangi taomlar tanlashga qaytish imkoniyati (savatcha saqlangan holda).
- **Chek va Ofitsiantga ko'rsatish**: Buyurtma tafsilotlari aks etgan chek ekrani.
